Oregon Trail .pix gallery

Reads and renders every .pix file under app/src/main/assets/art/ live in the browser — edit a file and refresh, no build step. Must be served over HTTP (browsers block directory listing over file://): run python3 -m http.server 8000 from the repo root, then open http://localhost:8000/pix-gallery.html.

    Select a sprite from the list.
